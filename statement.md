# Problem Statement and System Scope

## 1. Problem Statement
Small medical shops and pharmacies often face problems like running out of medicines, losing money because medicines expire unnoticed and making mistakes in bill calculations. They need a simple and reliable tool to track medicine batches in real time, calculate customer bills automatically and warn staff about stock issues without needing expensive internet servers.

## 2. Scope of the Project
The Pharmacy Inventory Management System helps small and medium medical shops manage their daily stock completely offline. The system separates prescription medicines from over-the-counter medicines, saves all records safely in a CSV file, creates customer bills with taxes included and checks for medicines that are running out or have crossed their expiry date.

## 3. Target Users
* **Pharmacists:** To check medicine stock, sell items to customers and create bills.
* **Store Managers:** To add new medicines, update stock quantities and remove expired medicines.

## 4. High-Level Features
* **Medicine Management:** Add new medicines, view current stock and update quantities using object-oriented Java concepts.
* **Safe File Storage:** Save and load medicine data directly from a local CSV file so no data is lost.
* **Smart Billing:** Create customer orders, stop sales if stock is too low and calculate total costs with taxes.
* **Automatic Alerts:** Quick warnings for medicines that are running low and medicines that are expired.
